# 微网与外部电网电力调控策略 · Microgrid Scheduling under PV Forecast Uncertainty

**2026 年全国大学生数学建模竞赛 C 题 · 陕西赛区省级一等奖**

144 时段（10 分钟）混合整数线性规划调度 + BP 残差修正 + 95% 经验预测区间 + 4 时刻滚动优化 + 动态电价重算，一年 365 天全流程可复现。

Pure `numpy / scipy / scikit-learn` — **no commercial solver required**（MILP 走 SciPy 内置 HiGHS），clone 下来装三个包即可运行。

---

## 一、问题与建模思路

微网由外部电网购电 + 屋顶光伏 + 一组储能电池构成，目标是在满足供需平衡与储能物理约束的前提下把全年购电成本压到最低。题目分四问递进：

| 问题 | 场景 | 建模方式 |
|---|---|---|
| Q1 | 电价/负荷/光伏预测固定 | 确定性 MILP，储能低储高发 |
| Q2 | 负荷与光伏逐日波动，缺电按 5 倍电价应急购电 | 两阶段：日前计划 + 实际执行，用**安全裕度** m 提高计划负荷、压低计划光伏 |
| Q3 | 每天 0/6/12/18 时更新光伏预报 | BP 修正预报残差 → 95% 经验区间下界作保守输入 → 滚动重优化未执行区间 |
| Q4 | 外网电价实时波动 | 把 Q2 / Q3 框架中的固定电价替换为附件 4 动态电价重新求解 |

关键约束：储能 12000 kWh 容量、SOC ∈ [1200, 10800]、充放电功率 ≤ 5000 kW、往返效率 0.9、充放电互斥；事后 SOC 跨日连续传递，不做每日归零。

## 二、主要结果

| | 年总成本 | 应急购电量 | 相对基准 |
|---|---|---|---|
| Q1 典型日 | 35,126.95 元 / 59,482.70 kWh | — | — |
| Q2（m=0%） | 2,548.40 万元 | 2,863,643.71 kWh | 基准 |
| Q2（m=5%，最优） | **2,393.79 万元** | 2,002,229.46 kWh | 成本 −6.07%，应急 −30.1% |
| Q3 滚动 + BP | **1,522.75 万元** | 239,542.57 kWh | — |
| Q4-2 动态电价 | 2,511.32 万元 | 2,002,188.56 kWh | — |
| Q4-3 动态电价 + 滚动 | **1,617.82 万元** | 239,720.21 kWh | 成本 −35.6%，应急 −88.0% |

> 注：以上为竞赛原始附件上的结果。仓库自带的合成数据只为验证代码，跑出来的数值与上表无关。

两个反直觉的结论：

1. **安全裕度不是越大越好。** 0/2/5/8/10% 五档里 5% 总成本最低，超过 5% 计划层过度保守，省下的应急成本抵不过多买的正常电。
2. **滚动重优化频率不是越高越好。** 从题目规定的 4 次加到 6 次、8 次，年成本基本不变（874,860 → 875,389 → 875,567 元，样本期），主要收益来自预测修正本身而非调整频次。

## 五、几个值得看的实现细节

**1. 用 LP 代替 MILP，并给出等价条件。**
储能的充放电互斥本来需要 0-1 变量，一天 144 个时段就是 144 个二进制变量，全年 365 天 × 5 档裕度 × 多情景会让求解时间失控。代码里 `EXACT_BINARY_MILP = False` 时走 LP 松弛，理由是：外购电价非负、往返效率 < 1 时同时充放电只会增加成本、不会出现在最优解中，因此 LP 与 MILP 最优目标值一致。论文仍按严格 MILP 表述模型，需要逐项核验二进制变量时把开关改成 `True` 即可。这是全篇最省事也最容易被追问的一处取舍，注释在文件头第 449–450 行。

**2. 训练集按时间切分，不随机切。**
BP 网络学习「附件 3 原始预报 → 实际光伏」的系统偏差，前 80% 时间样本训练、后 20% 检验。随机划分会把未来样本混进训练集，测试指标虚高。这对预测类项目是硬要求。

**3. 跨午夜预报的归属。**
18:00 发布的未来 24 h 预报，其中落在次日的那些值必须归到次日目标时刻，不能挂在发布日期上。`load_attachment3` + `get_forecast_row` 里专门处理了这一点，否则会出现整段预报错位。

**4. 滚动优化冻结已执行区间。**
每次只用最新预报重优化「尚未执行」的时段，已执行决策不再改写；优化目标里也刻意排除未来真实数据，避免信息穿越（`optimize_q3_stage` / `run_q3_day`）。

**5. 95% 区间用经验分位数。**
按预测提前量分组，取修正后残差的 2.5% / 97.5% 分位数构造区间，不假设正态。光伏误差在实际数据里明显偏态厚尾；样本不足 20 的提前量档退回全体分位数，避免小样本抖动。

## 六、已知局限

- 光伏特征只用了原始预报、前 1/2/3 日同小时实际值、日周期 sin/cos 和提前量，没有气象变量（题目未给），暴雨/沙尘这类突变天气刻画不足。
- 电价假设在调度阶段完全已知，未建模电价预测误差。
- 未计储能循环寿命折旧（题目未给单价），目标函数只含购电成本。
- 单文件实现，未拆包；`main()` 一次跑完四问，没有 CLI 参数控制跑哪一问。
